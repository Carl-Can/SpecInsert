# 预置剧本生化知识参考手册

手动引用本文件获取四个核心剧本的生化背景知识，用于扩充知识库或调试 Agent 推理质量。

## 场景 1：硅谷生物黑客猝死疑案（biohacker）

**核心药物组合**：雷帕霉素（5mg/周）+ 二甲双胍（1000mg/天）+ 司美格鲁肽（0.5mg/周）+ NMN

**关键生化路径**：
- 二甲双胍 → 抑制线粒体复合物 I → ↑AMP/ATP 比值 → 激活 AMPK → 自噬启动信号
- 雷帕霉素 → 抑制 mTORC1 → ULK1 激活 → 自噬通量增加
- 两药协同 → 自噬超载（无法及时降解自噬体）→ 线粒体大量降解 → 氧化磷酸化能力骤降 → 无氧糖酵解补偿 → 乳酸堆积
- 司美格鲁肽 → 延迟胃排空 35~50% → 二甲双胍吸收峰值升高 20~40% → 进一步加剧线粒体抑制

**确诊标志物**：乳酸 >4 mmol/L、血浆 NMN 代谢物、线粒体膜电位（JC-1 检测）

**干预方案**：停服雷帕霉素，补充辅酶 Q10（200mg/天）+ L-肉碱（2g/天），错开二甲双胍与司美格鲁肽给药窗口 ≥4 小时

## 场景 2：西柚汁+他汀肌溶解（grapefruit）

**核心物质**：阿托伐他汀 + 西柚汁（呋喃香豆素：6',7'-二氢香柠檬素/DHB、香柠檬素/bergamottin）

**关键生化路径**：
- 呋喃香豆素 → 对肠道 CYP3A4 产生不可逆共价结合（自杀性抑制）
- 单次饮用 200mL → CYP3A4 活性抑制持续 24~72 小时
- 阿托伐他汀首过代谢 ~50% 依赖 CYP3A4 → 生物利用度升高 8~12 倍（Cmax 升高 770%）
- P-gp 转运体同时受抑 → 肠道外排减少（双重增毒机制）
- 他汀浓度暴增 → HMG-CoA 还原酶过度抑制 → 辅酶 Q10 合成受阻 → 线粒体 ATP 耗竭 → 肌细胞膜破损 → 横纹肌溶解

**确诊标志物**：CK >10,000 U/L、肌红蛋白尿（酱油色）、血清阿托伐他汀浓度（如可检测）

**鉴别排除**：剧烈运动史（无）、病毒性心肌炎（无发热/心电图异常）、多发性肌炎（无抗体阳性）

## 场景 3：医用乙醇解甲醇（methanol）

**核心酶动力学**：醇脱氢酶（ADH）对底物的亲和力差异

| 底物 | Km (ADH) | 相对结合力 |
|------|----------|-----------|
| 乙醇 | ~1 mM | 高（10~20倍优势）|
| 甲醇 | ~10 mM | 低 |

**毒性产生路径**：
- 甲醇本身毒性低 → ADH 氧化 → 甲醛（剧毒，~30分钟半衰期）→ ALDH 氧化 → 甲酸
- 甲酸 → 抑制线粒体复合物 IV（细胞色素 c 氧化酶）→ 组织缺氧（即使 PaO₂ 正常）
- 视网膜神经节细胞富含细胞色素 c 氧化酶 → 优先受损 → 视力丧失

**乙醇解毒机制**：
- 维持血乙醇 100~150 mg/dL → ADH 活性位点被完全占据
- 甲醇无法代谢 → 以原形经肾脏排出（肾脏排甲醇半衰期 ~40~70 小时）
- 辅助：叶酸（增强甲酸转化为 CO₂+H₂O）、碳酸氢钠（纠正酸中毒）
- 现代替代：甲吡唑（Fomepizole，4-MP），ADH 特异性抑制剂，Ki ~0.1 μM

## 场景 4：沙利度胺分子胶反转（thalidomide）

**关键蛋白**：Cereblon（CRBN）→ CUL4A-RBX1-DDB1-CRBN（CRL4^CRBN）E3 泛素连接酶复合物

**致畸机制（1950s）**：
- 沙利度胺结合 CRBN 的三色氨酸残基结合腔（Trp380/Trp386）
- 招募 SALL4（Sal-like protein 4）→ E3 泛素化降解 → 肢体血管新生受阻 → 海豹肢（phocomelia）
- 同时降解 p63 → 进一步扰乱四肢外胚层发育

**骨髓瘤治疗机制（1998-2006）**：
- 相同 CRBN 结合 → 但在浆细胞中招募不同底物：IKZF1（Ikaros）和 IKZF3（Aiolos）
- IKZF1/3 是浆细胞存活的关键转录因子（调控 IRF4 → MYC 癌基因网络）
- CRL4^CRBN-沙利度胺复合物 → IKZF1/3 泛素化 → 26S 蛋白酶体降解 → IRF4↓ → MYC↓ → 浆细胞凋亡

**开创意义**：
- 首个被阐明的"分子胶降解剂（Molecular Glue Degrader）"机制
- 催生了 CELMoD 类药物：来那度胺（Lenalidomide）、泊马度胺（Pomalidomide）
- 进而影响了 PROTAC（靶向蛋白降解嵌合体）整个领域的崛起
